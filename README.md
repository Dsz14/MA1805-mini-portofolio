01.Drawing - For the first portfolio, i have created an emoji with a live background. I have created a meteor with shooting stars in the background where lines starts appearing at random locations that makes it identical to shooting stars. The background colour supports the theme as the primary colours for meteors are red, and orange. I also wanted to establish the agressiveness and the chaotic appearance of the emoji by including colors that represent danger (red).
